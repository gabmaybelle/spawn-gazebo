# Progress

What's done, what's broken, what's next. Newest entry first. Each session adds a row before it
ends, saying what changed, what the game test counted, what the proof run was (the feature off,
which checks fail, code put back), what was learned, and what was deliberately not done.

## Where things stand

- **Done:** Spawn Gazebo for Minecraft 26.3 (this branch) and 1.21.1 (the `1.21.1` branch), Fabric and NeoForge, every change so far released (versions: the GitHub releases): a round stone gazebo at the world spawn in the local wood (or the wood its biome is known for when no trees grow nearby), a protected radius, a starter chest whose kit another mod can supply, lava near it set to stone, and `/spawngazebo build` for existing worlds (lifts anyone standing there onto the floor, refuses to build on top of a gazebo); client game test (settings, a new world's gazebo, protection inside and outside the radius, Lootr, the build command), CI on every push.
- **Broken:** Nothing known.
- **Next:** Release the Paper plugin (`paper/`, branch `paper`) as a new loader: merge the branch, release prep, a hand play on a Paper server (join it and try breaking, placing and a bucket inside the gazebo, which the server test can't do without a player), then the listing on Hangar. A 1.20.1 version only if players ask for one.
